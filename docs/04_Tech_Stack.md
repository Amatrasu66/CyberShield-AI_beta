# Tech Stack

## Frontend
- React
- TypeScript
- Tailwind CSS
- Vite
- Chart.js (~installed dependency)
- Web Crypto API (browser cryptography engine: SHA-256/SHA-512, AES-256-GCM, PBKDF2-SHA256, HMAC-SHA256, base64/hex, secure random)

## Backend
- Python
- Flask
- cryptography (PyPI): AES-256-GCM, PBKDF2-HMAC-SHA256
- hashlib (stdlib): SHA-256, SHA-512, SHA-1, MD5
- sqlite3 (stdlib): isolated in-memory sandbox for the SQL Playground

## Machine Learning (planned)

- Pandas
- NumPy
- Joblib
- Inference modules exist as placeholders; no model is loaded at runtime today.
