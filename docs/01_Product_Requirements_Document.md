# Product Requirements Document (PRD)

## Target Users
- Students
- Faculty
- Internship evaluators

## Functional Requirements
- User authentication
- Dashboard
- Website scanner
- Email phishing detection
- Password analysis
- Log analysis
- PDF report generation
- Cryptography Lab (hashing, AES-256-GCM encryption, base64/hex encoding)
- SQL Injection Playground (isolated educational sandbox with fixed scenarios)

## Non-functional Requirements
- Responsive UI
- Fast response times
- Modular architecture
- Free deployment stack
